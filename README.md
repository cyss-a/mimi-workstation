## 🏗 架构

```
┌────────────────────────┐                ┌────────────────────────────┐
│  GitHub Pages (公开)    │   静态托管      │  Supabase（默认云端后端）    │
│  cyss-a/mimi-workstation │ ──────────────▶│  app_data 表（一行/家庭）   │
│  (前端 SPA, 无后端)      │   零配置        │  前端仅持 publishable key   │
└────────────────────────┘                └────────────────────────────┘
        │ 云端不可用时
        ▼
┌────────────────────────┐
│  浏览器 localStorage     │ 兜底，断网/异常时自动使用，刷新不丢
└────────────────────────┘
```

- 前端：纯 HTML + CSS + JS（ES Modules），零依赖，单页面应用
- 数据后端（二选一，设置里切换）：
  - **Supabase（默认·零配置）**：复用现有 Supabase 项目，前端只持公开 `publishable` key，无需任何账号；写入用 upsert 合并，绝不覆盖彼此数据
  - **本地（localStorage）**：数据存本机浏览器，开箱即用、断网可用
- 任意云端失败都会静默回退到本地，保证页面永远可用
- 每日内容轮换：`js/daily.js` 用「日期种子 + 确定性洗牌」保证拼音/科普/跟读每天自动换一批，近期不重复

## 🚀 部署（静态站点）

仅需把 `public/` 内容作为静态站点发布即可。当前使用 **GitHub Pages 分支部署**：

- 把 `public/` 内容推到 `mimi-workstation` 的 `main` 分支根目录
- 仓库 **Settings → Pages → Source → Deploy from a branch → `main` → `/ (root)`** 开启后，每次 push 到 main 自动更新站点
- 站点地址：`https://cyss-a.github.io/mimi-workstation/`

> GitHub Pages 只是「静态文件托管」，孩子打开即用，不需要任何 Token。
> 数据走 Supabase（默认）或本地，与 GitHub 账号无关。

## 🔒 安全

- 默认 Supabase 模式只持公开 `publishable` key，无法删库/改表结构，仅能读写本家庭那一行
- 本地模式数据只在自己浏览器里，不上传任何服务器
- 设置里提供「导出 / 导入」JSON 备份，换设备或清缓存可一键恢复，无需注册账号

## 💻 本地开发

直接用静态服务器打开 `public/` 即可（ES Module + fetch 需经 http，不能用 file://）：

```bash
cd mimi-workstation/public
python3 -m http.server 8137
# → http://127.0.0.1:8137
```

可选：`server/` 下有一个 Express 开发用后端（同时 serve 静态 + 模拟 `/api` 契约），非运行必需。
